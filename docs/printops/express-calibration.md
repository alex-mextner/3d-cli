# Экспресс-калибровка новой катушки

Один стол, 30–40 минут вместе с нагревом и фото. Что делаем: перед первой печатью новой катушкой
меряем pressure advance (PA) и flow ratio. Это две калибровки, которые политика D6 требует для
нового типа материала или вендора (block), а для новой партии — рекомендует (warn). Температура и
ретракт сюда не входят: их печатают отдельно и только по необходимости (см. «Опционально»).

Команды: [`3d calibrate`](../commands/calibrate.md) (`plan`, `gen combo`, `gen plate1`, `record`) и
[`3d print-preflight`](../commands/print-preflight.md). Генераторы: `lib/slicing/calibration_gen.py`
(отдельные тесты), `lib/slicing/calibration_plate.py` + `lib/slicing/calibration_plates/` (серия столов).
Принтеры: Klipper (K1 SE после root, U1 — когда для его модели появятся пресеты в `PRESETS`).

## Серия столов

Каждый стол — много тестов сразу, у каждого объекта свой параметр: он выставляется при входе
сопла в объект и возвращается при выходе (M221, PA, ускорение, длина ретракта), поэтому тесты не
искажают друг друга. Всё, что меняется по высоте и глобально (температура), печатается в конце,
отдельной башней в режиме «по объектам», позади остальных на `extruder_clearance_radius`
(K1 SE: 45 мм) и не выше `extruder_clearance_height_to_rod` (45 мм). Рядом с G-кодом пишется
`ИМЯ.json`: объект → параметры, bbox, полосы по Z, подписанные элементы и как читать — для
чтения по фото или камере.

| Порядок | Что | Когда |
|---|---|---|
| 0 | input shaper: `3d calibrate gen shaper` (команды в консоль, акселерометр) | раз на принтер и после ТО; **до стола 2** |
| 1 | `3d calibrate gen plate1` — «филамент»: PA-линии, MVS-полоса, flow-плитки, мосты 8/11/14 мм, нависания 45–60°, башня ретракта 0,4–1,2 мм, башня температуры 230→200 °C | каждая новая катушка (тип/вендор — обязательно, партия — по политике) |
| 2 | стол «механика» (ringing, VFA, размеры) — делается отдельно, на этом же движке | после input shaper и после ТО |

`--skip pa,flow` / `--only temp,retraction` выбирают тесты стола (id: `pa`, `mvs`, `flow`, `bridge`,
`overhang`, `retraction`, `temp`); пропущенные не печатаются и места не занимают — раскладка
собирается заново от переднего края. Пример (оранжевый PLA, PA и flow уже напечатаны комбо-столом):
`3d calibrate gen plate1 --printer k1se --filament-preset 'Orange PLA @K1SE' --skip pa,flow -o k1se_plate1_orange.gcode`
— ≈22 мин печати, ≈3 г; полный стол 1 — ≈25 мин.

Размеры — минимально достаточные для оценки: плитки 15×15 мм × 5 слоёв по 0,2 (сплошные), мосты
высотой 3,8 мм, нависания 5 мм, башни из блоков по 2,4 мм (ретракт по слоям 0,2 мм, температура —
0,3 мм).

## Бюджет времени

| Шаг | Время |
|---|---|
| `plan`, `gen combo`, preflight | 2 мин |
| нагрев + `START_PRINT` (хоминг, калибровка стола) | 5–8 мин |
| PA-линии (11 шт. по 26 мм) | ~1 мин |
| 5 flow-плиток 20×20×3 мм | ~8 мин (оценка Orca для K1 SE) |
| остывание, снятие, два фото | 5 мин |
| чтение и `record` | 5 мин |
| **итого** | **≈ 30 мин** |

Филамента ≈ 5 г.

## Шаги

1. **Что нужно.** Привязать катушку к голове (`3d printops spool load …`), затем:
   ```
   3d calibrate plan --printer k1se
   ```
   В списке будут `pressure_advance` и `flow_ratio` с уровнем FAIL или WARN. Если их нет —
   калибровка не нужна.
2. **Стол.** Нарезается пресетами, с которыми печатают принтер и катушка: `--filament-preset` —
   пресет катушки (обязателен), машина и процесс — из `slicer:` принтера в `fleet/printers.yaml`
   (или `--machine-preset`/`--process-preset`). Стоковые пресеты Orca не подставляются: без
   пресета команда откажет ([#293](https://github.com/alex-mextner/3d-cli/issues/293)). Цвет
   катушки идёт в `filament_colour` G-кода, по нему `loaded_filament_match` сверяет заправку:
   ```
   3d calibrate gen combo --printer k1se --filament-preset 'Black PLA babushkin @K1SE' -o k1se_combo_black_pla.gcode
   3d print-preflight k1se_combo_black_pla.gcode --printer k1se
   ```
   Нужен `STATUS: PASS`. Для другой температуры: `--nozzle-temp 215`. Для PETG: `--material PETG`.
3. **Контраст стола и пластика.** Калибровку читают по фото (человек или VLM), поэтому
   тёмный пластик печатаем на светлом столе, светлый — на тёмном. Чёрный PLA на чёрном PEI
   не читается ни камерой, ни на фото. Калибруется сама катушка, поэтому при низком контрасте
   меняем стол, а не пластик. Автоматическая проверка контраста по кадру камеры и цвету
   катушки — [#263](https://github.com/alex-mextner/3d-cli/issues/263); пока это проверка
   глазами перед стартом.
4. **Печать.** Стол чистый, без клея на зоне линий. Принтер idle. Старт обычным путём
   (`3d printer start …`).
5. **Свет.** Перед снимком включить подсветку, если выключена, а после — вернуть как было.
   Объекты Klipper (опрос `printer/objects/list`, только чтение, 2026-10-15):
   - K1 SE (после root): `output_pin LED` — `SET_PIN PIN=LED VALUE=1`, обратно `VALUE=0`;
   - U1: `led cavity_led` — `SET_LED LED=cavity_led WHITE=1`, обратно прежние значения
     (`color_data` из `printer/objects/query?led%20cavity_led`).

   Автоматическое включение и возврат света в `3d calibrate` — тоже
   [#263](https://github.com/alex-mextner/3d-cli/issues/263).
6. **Фото** — два снимка сверху, на столе, до снятия (линии тонкие и легко рвутся):
   - PA: все 17 линий с подписями в кадре, свет сбоку, низко над столом — так видна разница
     ширины;
   - flow: все 5 плиток, свет сбоку под острым углом к верхней поверхности — так видны
     щели и гребни.

## Что на столе

```
 сзади   [−10%] [−5%] [0%] [+5%] [+10%]     flow-плитки, слева направо

        100 ─────────                        PA-линии, подпись = PA × 1000
         ..                                  (0, 10, 20 … 100 → PA 0 … 0,10; PETG до 0,15)
         10 ─────────
 спереди  0 ──══════──
            6 мм  14 мм быстро  6 мм
           медленно (20 мм/с)  (120 мм/с)  медленно (20 мм/с)
```

Точный проход вокруг найденного значения: `--pa-range 0.03:0.05 --pa-step 0.0025` (подписи с
точкой: 42.5 = 0,0425).

- **PA-линии** печатаются сразу после `START_PRINT` на голом столе, высота первого слоя
  (0,2 мм), ширина 0,5 мм. Перед каждой линией идёт `SET_PRESSURE_ADVANCE ADVANCE=<значение>`.
  PA и `M221` действуют на всю печать, поэтому перед блоком стоит `M221 S100`, а после него PA
  возвращается к заводскому (K1 SE: 0,04) и ускорение — к ускорению пресета. Линии пишутся с
  относительной экструзией (M83); если слайс не в этом режиме, `gen combo` откажет.
- **Flow-плитки** нарезает Orca. Плитки печатаются при заводском PA. Перед каждым заходом в
  плитку (на каждом слое) стоит её `M221 S90…S110`, а перед `END_PRINT` — `M221 S100` и
  заводской PA.

## Чтение по фото

Одни и те же критерии для человека и для VLM (план §8.2, шаг 3). Ответ — номер линии или плитки,
допускается «между двумя».

### PA

Смотреть на два перехода скорости в каждой линии:

| PA | вход в быстрый участок (медленно → быстро) | выход (быстро → медленно) |
|---|---|---|
| мал | линия тоньше, недоэкструзия | утолщение, капля |
| велик | утолщение | линия тоньше, разрыв |
| верный | ширина ровная | ширина ровная |

Выбрать линию с самой ровной шириной на обоих переходах. **PA = подпись / 1000**.
Если две соседние одинаково хороши — среднее (подписи 35 и 40 → 0,0375).
Если лучшая линия крайняя (0 или 80), значение вне диапазона. Тогда печатаем башню
`3d calibrate gen pa` (PA 0…0,15 по высоте).

### Flow

Верх плитки, слева направо: 90, 95, 100, 105, 110 % от `filament_flow_ratio` пресета.
Таблицу значений `gen combo` печатает в отчёте (K1 SE, Generic PLA 0,98:
0,882 / 0,931 / 0,980 / 1,029 / 1,078).

- **мало**: между линиями верхнего слоя видны щели, просвечивает заполнение;
- **много**: гребни, шероховатость, наплывы по краям, «перепаханная» поверхность;
- **верно**: линии сомкнуты, поверхность гладкая, без гребней.

Выбрать самую гладкую плитку без щелей. Если граница между двумя — их среднее.

## Запись

```
3d calibrate record pressure_advance --printer k1se --head T1 --spool 42 \
    --values pressure_advance=0.035 --method pa_lines --evidence <url фото>
3d calibrate record flow_ratio --printer k1se --head T1 --spool 42 \
    --values flow_ratio=0.98 --method flow_tiles --evidence <url фото>
3d calibrate plan --printer k1se          # должно стать PASS
```

Значения пока переносятся в профиль слайсера вручную (D10: профили в `profiles/` + `3d profiles
sync`). `3d calibrate apply` из #168 пока не реализован. Потом `3d calibrate check FILE.gcode
--printer k1se` сравнит футер G-кода с записью.

## Опционально (вне 30–40 минут)

- **Полная температурная башня** — `3d calibrate gen temp` (230→200 °C для PLA, блоки по 8 мм;
  K1 SE ≈43 мин, ≈8 г), когда мини-башни стола 1 мало (широкий диапазон вендора, новый тип).
  Башня нарочно выходит за обычное окно: если её первая (самая горячая) температура, 230 °C для
  PLA или 250 °C для PETG, выходит за `nozzle_temp_min/max` катушки, `filament_temp_range` в
  preflight даст FAIL (холодные блоки он не проверяет) — проверьте остальные пункты и запускайте
  `3d printer start … --force`.
- **Ретракт** — отдельно, только при нитях/паутине на обычной печати
  (`retraction`, метод `retraction_tower`).
- **Input shaper** — от катушки не зависит. Делается один раз на принтер и после ТО:
  `3d calibrate gen shaper`.
